# CGI Project 2 - Helicopter Scene

## Repository Overview

An interactive WebGL scene developed for Computer Graphics and Interfaces (CGI), featuring a helicopter flying over a city built from geometric primitives. The demo includes animated rotors, altitude and flight-speed controls, falling cargo, and multiple viewing angles.

---

## Controls

Use the keyboard to control the helicopter and switch views. Letter shortcuts use lowercase keys.

| Action | Keyboard / On-screen Control |
| --- | --- |
| Ascend / descend | Hold `Arrow Up` / `Arrow Down` |
| Accelerate along the circular flight path | Hold `Arrow Left`; release it to slow down |
| Drop a cargo box | `Space` |
| Select the adjustable axonometric view | `1` |
| Rotate the adjustable view | Drag the **Theta** and **Gamma** sliders while view `1` is active |
| Select the front view | `2` |
| Select the top view | `3` |
| Select the side view | `4` |
| Display wireframe / solid geometry | `w` / `s` |

Gain altitude before accelerating: forward flight becomes available at the minimum safe height. The helicopter follows a fixed circular route.

The `5` key selects an unfinished camera mode: it keeps the current view and hides the sliders.
